# Rapdex — suporte

Canal público de suporte da extensão **Rapdex — Video Speed Controller**.

O código não vive aqui. Este repositório existe para você relatar problemas e
sugerir melhorias.

## O que fazer

| Situação | Onde |
|---|---|
| A velocidade não funciona em algum site | [Relatar site](../../issues/new?template=site-nao-funciona.yml) |
| Ideia de melhoria | [Sugerir](../../issues/new?template=sugestao.yml) |
| Dúvida de uso | [Perguntar](../../issues/new?template=duvida.yml) |

Antes de abrir, dê uma olhada nas [issues existentes](../../issues) — pode ser
que o problema já esteja mapeado.

## Privacidade

O Rapdex não coleta nada. Sem conta, sem servidor, sem rastreamento. As
estatísticas de tempo recuperado ficam apenas no seu navegador.

Quando você usa o botão de reportar dentro da extensão, ela apenas **abre esta
página com alguns campos preenchidos** — o domínio do site, a versão da extensão
e o navegador. Nada é enviado sem você revisar e clicar em enviar, e a URL
completa da página que você estava vendo nunca é incluída.
